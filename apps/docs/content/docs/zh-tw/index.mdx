Kilin 是一個本機、CLI 優先的工作流程執行環境。你可以用一般檔案定義有限工作流程，在執行前驗證，並透過已安裝的 Codex、Claude Code 或 OpenCode 執行。

Kilin 讓編排保持明確：

- 工作流程是專案或使用者範圍內的檔案；
- 執行附著於前景 CLI；
- 核准是明確的屏障；
- 可寫工作不會與其他節點重疊；
- 結果、日誌、決策和血緣保留在本機，且可檢查；
- 可選的 Viewer 只繫結本機迴路位址。

## 從這裡開始

1. [安裝 Kilin](/zh-tw/getting-started/installation)。
2. [建立並驗證工作流程](/zh-tw/getting-started/quickstart)。
3. 瞭解[工作流程模型](/zh-tw/concepts/workflows)。
4. 瞭解如何以人類或 Agent 身分[觀察執行](/zh-tw/concepts/monitoring)。
