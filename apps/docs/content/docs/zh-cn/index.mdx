Kilin 是一个本地、CLI 优先的工作流程运行时。你可以用普通文件定义有限工作流程，在执行前验证，并通过已安装的 Codex、Claude Code 或 OpenCode 运行。

Kilin 让编排保持明确：

- 工作流程是项目或用户作用域内的文件；
- 执行附着于前台 CLI；
- 审批是明确的屏障；
- 可写工作不会与其他节点重叠；
- 结果、日志、决策和血缘保留在本地，且可检查；
- 可选 Viewer 只绑定本地回环地址。
